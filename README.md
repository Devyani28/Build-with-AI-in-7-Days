# Build-with-AI-in-7-Days
Learn modern AI by building real-world projects in just 7 days. Covers LLMs, Prompt Engineering, RAG, AI Agents, MCP, and production-ready AI applications.

# README.md

```md
# Build an AI Agent in 7 Days

Most AI courses teach lots of theory and very little implementation.

In this repository, we'll build ONE chatbot and improve it every day until it becomes a production-ready Agentic AI application.

## What you'll build

Day 1 - Talk to an LLM using APIs.

Day 2 - Build a chatbot UI using Gradio.

Day 3 - Integrate LangChain.

Day 4 - Convert the chatbot into an AI Agent by adding tools.

Day 5 - Add memory and checkpointing.

Day 6 - Connect external knowledge using RAG and databases.

Day 7 - Build a production-ready multi-session AI Agent.

## Prerequisites

- Basic Python knowledge
- VS Code installed
- Basic understanding of variables, functions and loops

## Course Outcome

By the end of this course, you'll know:

- LLMs
- Prompt Engineering
- LangChain
- AI Agents
- Tool Calling
- Memory
- Checkpointing
- Embeddings
- RAG
- Vector Databases
- Streamlit
- Production-ready AI architectures

Let's build AI instead of just learning AI.
```
