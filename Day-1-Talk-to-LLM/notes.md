## What is a Model?

A trained algorithm that learns patterns from data.

Examples:
- GPT
- Gemini
- Claude
- Llama

## What is an LLM?

A language model trained on massive datasets.

## Types of AI

- Predictive AI
- Generative AI

## How do we communicate with an LLM?

User -> Client -> API -> LLM -> Response

## What is an AI Agent?

An LLM that can use tools to solve problems.

## Fine Tuning

Use when you want to change model behaviour.

## RAG

Use when you want to provide external or organisation specific knowledge.

## Embeddings

Numerical representation of text used for semantic search.

## Temperature

Controls randomness of the output.

0.0 -> Deterministic

1.0 -> Creative

## Messages

- System Message
- User Message
- Assistant Message
